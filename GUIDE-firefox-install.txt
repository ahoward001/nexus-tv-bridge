Nexus → TradingView Bridge — FIREFOX
====================================
Version 4.1.3 — signed by Mozilla, installs permanently, updates itself.


INSTALL — two clicks
--------------------
1. Open this link IN FIREFOX (not Chrome — Chrome can't use this file):

     https://github.com/ahoward001/nexus-tv-bridge/releases/latest

2. Scroll to "Assets" at the bottom and click the blue

     nexus-tradingview-bridge-firefox-v<latest>.xpi

   Ignore "Source code (zip)" and "Source code (tar.gz)". Those are generated by
   GitHub automatically and are NOT the extension.

3. Firefox asks "Add Nexus → TradingView Bridge?" → click ADD.

That's it. It's permanent, and it updates itself from now on — Firefox checks
about once a day and installs new versions silently. You never repeat this.


THEN DO THIS OR NOTHING WORKS
-----------------------------
Firefox MV3 treats host permissions as OPTIONAL. They are NOT granted at install
the way Chrome grants them. Until you grant them, the extension cannot read Nexus
or write to TradingView, and it looks silently broken — no error, just nothing.

  about:addons → Nexus → TradingView Bridge → Permissions
  → enable access for dashboard.nexusfutures.net and tradingview.com

This is the single most likely reason a Firefox install "does nothing".


THE REST OF THE SETUP
---------------------
STEP 1. Log in to Nexus at dashboard.nexusfutures.net and leave a tab open on the
  ticker you trade. The extension reads YOUR logged-in session; it stores no
  password, cookie, or token of its own.

STEP 2. Open your TradingView chart. It must already have the "Nexus Futures"
  indicator on it (any version — V3, V4.x). That one comes from Nexus, not from me.

STEP 3. Add the second indicator, "Nexus Strike Metrics". This is the Pine script
  nexus-strike-metrics.pine; it draws the per-strike Score / OI / GEX columns.
  The Pine editor is part of TradingView, so this is identical in every browser.

    a. Open nexus-strike-metrics.pine in any text editor. Select all, copy.
    b. Open the Pine Editor. It is NOT in the bottom toolbar on current
       TradingView — click the grid/apps icon at the BOTTOM-RIGHT of the chart
       (the 3x3 dots), and pick "Pine Editor" under PRODUCTS. Star it there and it
       stays handy.
       (Once the indicator is ON the chart, the faster way back to its code is the
       { } brackets icon on its row in the chart legend — that opens this script's
       source directly. Use it when re-pasting an updated version.)
    c. If a banner says "This is a historical version of the script", you are in a
       READ-ONLY view and pastes will silently do nothing. Use the script-name
       dropdown to get back to the current version first.
    d. Click into the code area, select all (Ctrl+A, or Cmd+A on Mac), paste. Replacing the
       default template is correct.
    e. Ctrl+S (Cmd+S on Mac) to save the SCRIPT. Name it "Nexus Strike Metrics" if asked.
       Confirm it says Saved with no red compile errors.
    f. Click "Add to chart" — EXACTLY ONCE. Each click adds another copy, and the
       extension writes to whichever it finds first, so a duplicate makes the
       visible one look frozen. (To remove a duplicate: click its legend title,
       then press Delete. The legend's own remove button ignores scripted clicks.)
    g. Do NOT click "Publish script" — that shares it publicly. You want Ctrl+S.
    h. Click the chart, then Ctrl+S again to save the LAYOUT. This is a SECOND,
       DIFFERENT save. Skipping it is the #1 reason the indicator vanishes on
       reload.
    i. Check the legend now lists BOTH "Nexus Strike Metrics" and "Nexus Futures".

  SETUP-STRIKE-METRICS.md has the same steps plus a ready-made prompt if you'd
  rather have an AI assistant do it for you.

STEP 4. Click the green tab on the right edge of the chart (or the toolbar icon).
  It reads Nexus, pastes the levels into Nexus Futures, and fills the strike
  columns. Every click refreshes everything.

STEP 5. Optional — price alerts. Open the extension's Settings (the gear in the
  cluster under the sync button) and turn on price alerts. They are OFF until you
  do. Settings apply on the next sync — click the green button after changing them.

Nothing else needs configuring. There are no selectors to set.


UPDATES
-------
Automatic. Firefox polls for new versions roughly daily and installs them without
asking. To force one immediately: about:addons → gear icon → Check for Updates.

The Pine indicator is the exception — it is NOT part of the extension and does not
update with it. If a release says the Pine script changed, re-paste it (Pine Editor
→ select all → paste → Ctrl+S). You'll be told explicitly when that's needed.


HOW FIREFOX DIFFERS FROM CHROME
-------------------------------
1. Host permissions are optional and must be granted by hand (see above). This is
   the big one.

2. Price alerts sample once a MINUTE rather than every 30 seconds. Chrome's alarm
   floor is 30s; Firefox's is 1 minute and it rejects anything shorter. So alerts
   are half as responsive here — a level touched and left inside one minute can be
   missed.

3. Firefox uses its own notification system, so the Chrome notification advice in
   the other docs doesn't apply. How long a notification stays on screen is an
   operating-system setting (Windows: Settings > System > Notifications).

Under the hood the manifest uses an event page instead of a service worker, and
carries an explicit add-on ID (without one, storage.sync silently fails to persist,
which means settings never save and the button appears broken).


IF SOMETHING LOOKS BROKEN
-------------------------
Check host permissions FIRST — see the section above. It's nearly always that.

After that, the most brittle part on any browser is the TradingView DOM: the paste
path finds the settings dialog and the Niveles field by selector. Firefox renders
the same DOM, so it should hold, but that's where to look.

Requires Firefox 128 or newer.

Everything else (README.md, SETUP-STRIKE-METRICS.md, SETUP-PHONE.md, the Pine
indicator, the iPhone shortcuts) is identical and applies unchanged.
